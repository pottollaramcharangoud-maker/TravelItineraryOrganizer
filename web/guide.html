User guide

Everything you need to run the console application, the Tkinter GUI and this web client, plus the validation rules that keep your data clean.

Getting started

Install Python 3.10 or newer. Clone the repository, then run python main.py for the console app or python run_gui.py for the desktop GUI. No third-party package is needed at run time. Install requirements-dev.txt only if you want to run the 76 automated tests with python -m pytest -q.

Using this web client

Add and edit

Use the toolbar buttons. Select a row, then choose Edit or Delete. Double-click a row to edit quickly.

Search

Type a keyword and press Enter to parse a sentence such as "trips to Paris under 3000 booked".

Tabs

Summary & Analytics shows metrics and charts; Warnings lists overdue and high-cost entries.

Offline

The app caches its shell, so it opens again without a network connection. Use Install app in the header.

Validation rules

  • Destination is required and limited to 200 characters.
  • Dates use YYYY-MM-DD and the end date cannot precede the start date.
  • Estimated cost must be numeric and non-negative.
  • Category and status must come from the predefined lists.
  • Imported CSV rows use the same rules; rejected rows are listed with line numbers.
