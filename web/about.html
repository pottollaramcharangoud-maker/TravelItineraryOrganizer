About this project

A focused Python application that organizes destinations, dates, notes and estimated costs with strict validation, reliable local storage, analytics and threshold warnings. It runs as a console app, a Tkinter desktop GUI and this installable offline web client.

What it does

Organize

Record trips with destination, dates, category, notes and cost, then edit or remove them.

Validate

Every field is checked for type, format and range before it reaches storage.

Find

Search by keyword, category or status, use fuzzy matching, or ask in plain English.

Analyse

Totals, averages, distributions, anomaly flags and a spend forecast.

Persist

JSON/CSV files or a transactional SQLite database, with locking and backups.

Export

Markdown, CSV, JSON and plain-text audit reports.

Architecture

LayerResponsibility
PresentationConsole, Tkinter GUI, web client
ApplicationMenu dispatch, input wrappers, natural-language query
Domain / ServiceCRUD, search, summaries, warnings and insights
PersistenceJSON/CSV with locking or SQLite with transactions

Technology

Python 3.10+ standard library, Tkinter, SQLite, pytest for 76 automated tests, Git and GitHub for source control, and Vercel for web hosting. The web client is a PWA with an offline service worker.
