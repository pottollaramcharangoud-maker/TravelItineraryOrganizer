Travel Itinerary Organizer

A focused Python application to organize destinations, dates, notes and estimated costs with validation, local persistence and actionable summaries. Built for StudentLife Hack, Project #52.

View on GitHub Run locally

Features

Interactive console & GUI

Menu-driven terminal interface plus a full Tkinter desktop application with sortable tables and dialogs.

Defensive validation

Looping input wrappers and domain checks reject invalid dates, costs, categories and statuses.

Local persistence

JSON/CSV storage that survives restarts and automatically recovers from corrupted files.

Search & filtering

Keyword, category and status filters for fast retrieval of stored itineraries.

Analytics

Totals, averages, distributions and ASCII bar charts for at-a-glance insight.

Threshold warnings

Flags overdue trips, non-positive durations and costs above the configured limit.

Multi-format export

Markdown, CSV, JSON and plain-text audit log reports.

Bulk import

Ingest legacy CSV datasets with row-by-row validation error logs.
